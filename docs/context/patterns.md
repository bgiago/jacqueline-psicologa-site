## Padrões de Commits

Seguir Conventional Commits:
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` mudanças em documentação
- `style:` formatação sem mudança de lógica
- `refactor:` refatoração sem nova feature ou fix
- `chore:` tarefas de manutenção
